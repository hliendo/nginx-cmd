# nginx-cmd

## English
`nginx-cmd` is an All-In-One gateway for Nginx administration.  
It integrates essential modules like Brotli, cron, fail2ban, and Certbot,  
providing simple commands for common server tasks.

### Features
- Quick Nginx setup
- Built-in Brotli compression
- Automation with cron
- Security with fail2ban
- SSL certificates with Certbot

## Castellano
`nginx-cmd` es un gateway Todo-en-Uno para la administración de Nginx.  
Integra módulos esenciales como Brotli, cron, fail2ban y Certbot,  
ofreciendo comandos simples para tareas comunes del servidor.

### Características
- Configuración rápida de Nginx
- Compresión Brotli integrada
